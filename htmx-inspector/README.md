# Web Inspector Pro

A professional Chrome extension for visual web inspection.

## Features
- **Visual Style HUD**: Hover over any element to see:
  - Font family, size, and weight
  - Calculated colors (with hex codes and visual previews)
  - Element dimensions and ID/Class info
- **Box Model Overlay**: Visualize layout with color-coded overlays:
  - **Orange**: Margins
  - **Green**: Padding
  - **Blue**: Content
- **Layout Visualizer**: Automatically highlights Flexbox and Grid containers.
- **Granular Control**: Toggle any specific inspector feature from the popup menu.

## Installation
1. Open Chrome and navigate to `chrome://extensions/`.
2. Enable **Developer mode** in the top right.
3. Click **Load unpacked**.
4. Select the `htmx-inspector` folder.

## Usage
1. Click the extension icon.
2. Toggle "Inspection Mode" to ON.
3. Use the checkboxes to enable/disable specific overlays (Styles, Box Model, Layout).
4. Hover over any element on the page.
